# Sinov videosi

Fayl: `aerobic-exercises-test.webm` (taxminan 12 soniya, WebM).

Bu umumiy aerobika klipi faqat admin panelidagi dieta video yuklash oqimini sinash uchun qo‘shildi; u ArniyGym murabbiylari tayyorlagan dars emas. Fayl `public` papkasidan tashqarida saqlangan, shuning uchun sayt uni ochiq statik video sifatida tarqatmaydi.
